Optional. Put these two files in a folder named "branding" next to capsule-link.zip in your
GitHub repository, and the cloud build bakes them into the installed apps:

  app-name.txt   one line: the name shown under the icon (Windows and Android)
  app-icon.png   square PNG, 512x512 or larger

Inside the apps, names and pictures still come from setup on the PC (and reach the phone with
each sync). This only changes what Windows and Android show before the app is opened.
